# Contributing

Thanks for helping make Hib Remover Ads better.

## An ad got through, or a site broke

Use the [issue forms](https://github.com/ZakariaHibaoui2/hib-remover-ads/issues/new/choose). Include the full address of the page, your browser and the Hib Remover Ads version (shown on its card in `chrome://extensions`). A screenshot helps.

## Changing the code

1. Fork the repository and create a branch.
2. Make the change. Keep it small and focused.
3. Run the checks:
   ```sh
   python -m playwright install chromium
   python tests/test_extension.py
   ```
   All 20 checks should pass.
4. Open a pull request describing what changed and how you tested it.

## Where things live

| Folder | Contents |
|---|---|
| `src/` | The extension. Load this folder unpacked to try your changes. |
| `src/rules/`, `src/content/generic.css`, `src/scriptlets/config.js` | Generated by `tools/filterlists.py`. Don't edit by hand. |
| `tools/filters.mjs` | Our own curated rules, compiled by `node tools/build.mjs`. Add missed ad servers here. |
| `tools/filterlists.py` | Downloads and compiles the community filter lists. |
| `installer/` | Windows installer source. |
| `docs/` | The website, served by GitHub Pages. |
| `tests/` | End-to-end, real-site and performance tests. |

## Ground rules

- No telemetry, analytics or remote code. Ever.
- Prefer skipping a filter over approximating it badly: a wrong rule breaks sites.
- By contributing you agree your work is licensed under GPL-3.0.
