Built on the lists the big blockers use

Hib Remover Ads compiles the same community filter lists that uBlock Origin and AdBlock rely on, then adds its own YouTube protection on top.

  • YouTube video adsAd instructions are removed from YouTube's player data before it can schedule an ad. Anything that slips through is muted and skipped.
  • Banners, popups and popundersOver 17,000 blocking rules from EasyList, uBlock filters, Liste FR and Liste AR.
  • TrackersEasyPrivacy and uBlock Privacy stop the scripts that follow you from site to site.
  • Anti-adblock wallsAbout 4,600 site-specific fixes switch off "please disable your ad blocker" checks.
  • Empty ad boxesMore than 15,000 hiding rules remove the gaps ads leave behind.
  • Your choice per sitePause it on any site with one click from the toolbar.

Install in one minute

It isn't on the Chrome Web Store yet, so the installer sets it up and walks you through the last three clicks.

  1. Run the installer

    Open HibRemoverAds-Setup.exe, pick your browser and click Install. If Windows shows "Windows protected your PC", click More info, then Run anyway.

  2. Turn on Developer mode

    Your browser opens its extensions page. Switch on Developer mode at the top right.

  3. Load it

    Click Load unpacked, press Ctrl+V in the folder box and click Select Folder. The installer already copied the folder path for you.

Questions

Something not working? Open an issue on GitHub with the site's address.

Is it really free?

Yes. There is no paid version and no account. The code is open on GitHub under the GPL-3.0 license.

Does it collect my data?

No. Everything runs inside your browser. It only stores your settings and the number of ads it blocked.

Windows says the installer is from an unknown publisher

Windows shows this for any program that isn't signed with a paid certificate. Click More info, then Run anyway. The installer's source code is in the repository if you want to check it.

Chrome says "Disable developer mode extensions"

Chrome shows this for any extension that isn't from the Web Store. Close it with the X. Hib Remover Ads keeps working.

A site stopped working or asks me to turn off my ad blocker

Click the Hib Remover Ads icon and choose Pause on this site. Ads come back only on that site. Please report it on GitHub so the next version can fix it.

How do I update it?

Run the newest installer, then click the reload arrow on Hib Remover Ads in your browser's extensions page.
