Install in one minute

Hib Remover Ads isn't on the Chrome Web Store yet, so you add it yourself. You only do this once.

  1. Download

    Get hib-remover-ads.zip.

  2. Unzip it

    Right-click the file and choose Extract All. Keep the folder somewhere you won't delete it, like Documents.

  3. Open extensions

    Paste into the address bar and turn on Developer mode at the top right.

  4. Load it

    Click Load unpacked and pick the folder you extracted. Pin it from the puzzle-piece menu to see the counter.

What it removes

Ads are stopped before they download, so pages also load faster.

YouTube ads
Pre-roll and mid-roll video ads, overlays, sponsored cards and Shorts ads. If one slips through, it gets muted and skipped.
Banners and popups
Around 130 ad networks are blocked, including Google ads, Taboola and Outbrain.
Trackers
Ad trackers that follow you from site to site are blocked too.
Empty ad boxes
The gaps ads leave behind are hidden, so pages look clean.

Questions

Something not working? Open an issue on GitHub.

Is it really free?

Yes. There is no paid version and no account. The code is open on GitHub for anyone to read.

Does it collect my data?

No. Everything runs inside your browser. The only thing it stores is your settings and the number of ads it blocked.

Chrome says "Disable developer mode extensions". What do I do?

Chrome shows this for any extension that isn't from the Web Store. Click the X to close it. Hib Remover Ads keeps working.

A site stopped working or asks me to turn off my ad blocker

Click the Hib Remover Ads icon and choose Pause on this site. Ads come back only on that site.

How do I update it?

Download the new zip, replace the files in your folder, then click the reload arrow on the extension in chrome://extensions.
